# ДЗ 6. SQLAlchemy

Модель для таблицы студентов из `students.csv` и класс `StudentRepository`, который делает INSERT и SELECT, грузит данные из csv и считает то, что просили в задании, просили студентов по факультету, уникальные курсы, оценки ниже 30 по курсу и средний балл по факультету

## Как запустить

```bash
pip install -r requirements.txt
python main.py
```

Скрипт создает файлик с базой `students.db` (тут sqlite), добавляет в нее `students.csv` и выводит результаты всех методов. При каждом запуске база создается заново, чтобы строки не дублировались

Чтобы запустить тесты:
```bash
pytest
```

Тесты работают с базой в памяти, файл `students.db` не трогают

## Как я понял неоднозначные места

- Одна строка csv - это одна оценка студента по одному курсу. Один и тот же человек в файле встречается много раз, причем на разных факультетах, и одна пара студент + курс тоже бывает несколько раз. Поэтому таблицу не делил на студентов и оценки, храню строки как есть с отдельным `id`
- Студенты по факультету -это уникальные пары фамилия + имя среди строк этого факультета, без повторов
- оценка ниже 30 - это строго меньше 30, 30 уже не входит. Возвращаю строки целиком, чтобы было видно факультет и саму оценку
- Средний балл по факультету - это среднее по всем строкам факультета. Для несуществующего факультета метод вернет none
- Если колонки в csv называются по-другому, их надо поправить в COLUMNS в начале main.py. Разделитель и кодировку можно передать в `load_csv`, по умолчанию запятая и utf-8 (файл с BOM тоже читается)
