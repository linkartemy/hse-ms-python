# ДЗ 4. FastAPI, pydantic

Сервис для обращений абонентов. Добавил обработку данных абонента, причины и времени обнаружения проблемы, добавил возможность делать несколько причин в одном запросе

## Как запустить

```bash
pip install -r requirements.txt
python main.py
```

Дальше можно открыть http://127.0.0.1:8000/docs и отправлять запросы оттуда. Каждое обращение сохраняется отдельным jsonом в папку `appeals/`

## Как я понял неоднозначные места

- Фамилия и имя - одно слово с большой буквы (дальше строчные), только русские буквы. Двойные фамилии через дефис пока не проходят
- Телефон только российский. Можно писать с пробелами, скобками и дефисами, в файл он сохраняется как +7XXXXXXXXXX
- Дата рождения не в будущем и не раньше 1900 года
- Причина - одна из трех: "нет доступа к сети", "не работает телефон", "не приходят письма". В задаче 3 их может быть несколько, поэтому поле сразу список `reasons`, одну причину тоже передаем списком. Повторять причину нельзя
- Время обнаружения проблемы не в будущем и не раньше даты рождения

## Пример запроса

```bash
curl -X POST http://127.0.0.1:8000/appeals/ \
  -H 'Content-Type: application/json' \
  -d '{
    "last_name": "Иванов",
    "first_name": "Иван",
    "birth_date": "1990-05-17",
    "phone": "8 (912) 345-67-89",
    "email": "ivanov@example.com",
    "reasons": ["нет доступа к сети", "не приходят письма"],
    "problem_detected_at": "2026-10-30T18:45:00"
  }'
```

В ответе придет путь к файлу: `{"status": "ok", "file": "appeals/Иванов_1a2b3c4d.json"}`

Если что-то не проходит проверку, FastAPI вернет ошибку 422 и в `detail` напишет, что не так. Например, с `"last_name": "иванов"` будет ошибка про заглавную букву в поле `last_name`. Проверка "проблема раньше даты рождения" смотрит сразу на два поля, поэтому у нее в `loc` только `body`
