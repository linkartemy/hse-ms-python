# ДЗ 3 по асинхронности

## Как запустить

```bash
pip install -r requirements.txt
python main.py
```

После запуска можно открыть http://127.0.0.1:8000/docs и поотправлять запросы
- `time` — сколько работала одна задача
- `total_time` — сколько занял весь запрос
- `parallel_faster_than_sequential` — получилось ли быстрее, чем если бы задачи шли последовательно, а не параллельно
