# ДЗ 7. CRUD на FastAPI

Доработал ДЗ 6: в `StudentRepository` добавил обновление и удаление записей (`update`, `delete`, плюс `get` по id), подключил класс к FastAPI и сделал эндпоинты для создания, чтения, обновления и удаления студентов

## Как запустить

```bash
pip install -r requirements.txt
python main.py
```

При первом запуске создается `students.db` и в нее грузится `students.csv`. Дальше csv загружается, только если база пустая, так что изменения через api остаются после перезапуска (если удалить вообще все записи, при следующем запуске csv загрузится заново). Чтобы начать с чистых данных, можно просто удалить `students.db`

Документация и форма для запросов: http://127.0.0.1:8000/docs

Тесты - `pytest`, они работают со своей базой во временной папке

## Эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/students/` | создать запись, ответ 201 с id |
| GET | `/students/` | список, можно фильтровать `?faculty=` и `?course=` |
| GET | `/students/{id}` | одна запись |
| PUT | `/students/{id}` | заменить запись целиком |
| PATCH | `/students/{id}` | поменять только переданные поля |
| DELETE | `/students/{id}` | удалить, ответ 204 |

Если записи с таким id нет, будет 404. Если данные не прошли проверку или id некорректный (меньше 1 или слишком большой для sqlite), 422

## Как я понял неоднозначные места

- Запись - это одна строка csv, то есть оценка студента по одному курсу, как в ДЗ 6. Поэтому CRUD по `id` строки, а не по студенту
- Оценка - целое число от 0 до 100 (в csv как раз такой диапазон), true/false не принимаются. Строки не пустые, пробелы по краям обрезаются
- id удаленных записей заново не выдаются
- Для обновления сделал и PUT, и PATCH: PUT требует все поля, PATCH только те, что меняются
- Методы из ДЗ 6 (студенты по факультету, курсы, оценки ниже 30, средний балл) остались в классе, отдельные эндпоинты под них в задании не просили

## Примеры

```bash
curl -X POST http://127.0.0.1:8000/students/ \
  -H 'Content-Type: application/json' \
  -d '{"last_name": "Смит", "first_name": "Федор", "faculty": "ФТФ", "course": "Физика", "grade": 75}'
```

Ответ: `{"last_name": "Смит", "first_name": "Федор", "faculty": "ФТФ", "course": "Физика", "grade": 75, "id": 216}`

```bash
curl -X PATCH http://127.0.0.1:8000/students/216 \
  -H 'Content-Type: application/json' -d '{"grade": 90}'

curl -X DELETE http://127.0.0.1:8000/students/216
```
